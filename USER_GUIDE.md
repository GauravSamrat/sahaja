# User guide

- **First launch** offers an empty workspace or editable Operation Independence starter tasks. Use **Start cycle** after waking and **End cycle** when finished. Correct wake time if needed. Midnight does not close a cycle.
- **Right now** uses your energy and time budget. Open **Mode and filters** to set internet, device, dimension and project focus. Choose **Begin**, **Complete**, **Later**, **Edit** or **Something else**. Use **Open time** for quick captures whose estimates are still unknown.
- **Tasks** provides quick capture, search, status filters and editing. In task details, enter one subtask per line. Prefix finished lines with `[x] `. You can archive, reopen and delete tasks. If a timer is running on the task, archiving, deleting or completing it records the elapsed session first.
- **Focus timer** supports pause, resume, stop and complete. Use **Correct duration** to record a revised total and stop. The timer uses elapsed wall time while running, including time asleep or minimized.
- **Activity** logs meditation, rest and naps and shows recent cycles, sessions and weekly totals. Logs are associated with the cycle open when the recorded activity began.
- **Money** tracks INR income and expenses. Pending income appears separately from received income. Correct entries or mark income received when it arrives. The calendar field is the transaction timestamp.
- **Workspace** manages dimensions, project goals, themes, imports and backups. Review the preview before approving selected AI tasks or choosing merge or replace. To reverse a restore, preview the recovery copy and replace with it.
- Press **N** for task details and **/** to focus task search on the Tasks screen.

## Planning and outreach

Use **Workspace → Plan with AI** to describe a goal and generate a prompt. Copy it into an assistant of your choice, then select **Go to JSON import** to paste its response. Review the preview and approve only the tasks and projects you want. Goal and prompt drafts are held in the current page. Sharing them with an assistant is a separate action you take outside SAHAJA.

Use **Workspace → Projects and goals → Add Outreach & Communication starter** to add an editable project and example tasks. The project uses the same task controls as the rest of the workspace.

## Activity and corrections

Choose Today, Current working cycle, Last 7 days, Last 30 days or All time. Calendar periods use local dates. The current-cycle filter follows the cycle across midnight. The summary counts tasks with a recorded completion in the period and adds time from saved sessions. A completion without a session adds no time. The task breakdown shows the recorded time inside the period beside the task’s full estimate when one is available.

Use **Correct session** on a history entry to update its timestamps, recorded duration or note. You can also change meditation, rest or nap to another of those activity types. Changes replace the existing session and adjust its linked task’s actual-duration field where applicable. Period totals count each session once. Two independently logged overlapping activities remain separate records. Correct the entries if they represent the same time.

## Feedback and sharing

**Workspace → Share or give feedback** copies the public app link or lets you write and copy feedback. You can paste it wherever you choose or open the public GitHub issue form. Posting there is optional and uses GitHub’s own account requirements. SAHAJA leaves your feedback unsent and includes no workspace records.
